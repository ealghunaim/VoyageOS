# Mobile app (Expo) — scaffold on your machine
This folder is intentionally empty in the starter. On your machine:

    npx create-expo-app@latest . --template blank-typescript
    npx expo install expo-notifications expo-secure-store

Then follow v0.5 build order in the root README. Screens to build first:
trip wizard → packing screen (Part 2 §2 wireframe) → timeline → debrief.
